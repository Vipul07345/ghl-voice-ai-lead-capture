# 📞 GHL Voice AI Lead Capture System

A realistic AI Voice Agent built with GoHighLevel that handles customer calls, collects lead information, and triggers automated notifications.

## 🚀 What It Does

The AI Voice Agent interacts naturally with callers and collects:

- 👤 Customer Name
- 📱 Phone Number
- 🛠️ Requested Service

After collecting the required information, the system processes the lead and sends an automated notification to the designated user/team.

## 🔄 Workflow

Customer Call
      ↓
GHL Voice AI Agent
      ↓
Natural Conversation
      ↓
Collect Customer Information
      ↓
Name + Phone + Service
      ↓
Create / Update Contact
      ↓
Trigger Workflow
      ↓
Send Notification
